# Features

This file distinguishes implemented repository capability from planned product capability.

## Implemented in Milestone 0 foundation

- Go module and first-party service shell.
- CLI entry point with `serve`, `version`, and `help` commands.
- Loopback-only default development listener at `127.0.0.1:8787`.
- Development health endpoint.
- Development status endpoint.
- Basic privacy/security response headers.
- Graceful process shutdown.
- Service endpoint tests.
- Architecture, protocol, security, competitive, contribution, and product documentation.
- GitHub Actions CI for formatting, tests, vetting, and build validation.

## Planned — Sync

- Persistent folder replication.
- Send/receive, send-only, and receive-only modes.
- Selective sync.
- Filesystem watching.
- Ignore patterns.
- Offline queues.
- Chunked and resumable synchronization.
- Efficient changed-block transfer.
- Bandwidth controls and schedules.
- File versioning.
- Conflict Center.
- Deletion safety controls.
- Integrity verification.
- Authoritative-copy labeling.

## Planned — Nearby

- LAN discovery.
- QR pairing.
- Optional PIN confirmation.
- File and folder transfer.
- Text, URL, and clipboard transfer.
- Drag and drop.
- Android share-sheet integration.
- Favorite devices.
- Background receiving.
- IPv4 and IPv6.
- Wi-Fi, Ethernet, and approved private-network transport.
- Resume and verification.

## Planned — Share

- Expiring links.
- One-use links.
- Download limits.
- Immediate revocation.
- Optional passphrases.
- Optional authenticated-recipient requirements.
- QR codes.
- Client-side end-to-end encryption.
- Encrypted metadata where practical.
- Peer-to-peer preferred delivery.
- Encrypted temporary relay/storage fallback.
- Automatic expiration and cleanup.

## Planned — Multi-user and administration

- Accounts and independently owned devices.
- Explicit folder ACLs.
- Read, write, contribute, receive-only, drop-only, and administrative grants.
- Device enrollment and revocation.
- Audit events.
- Transfer history.
- Migration Mode.
- Drop folders.
- Glaze UI web administration.
- Native Android client.
- Debian packaging.
- GoreeCloud Identity, Network, Notify, Manager, Photos, Drive, Search, API, Wardveil Security, Privacy Shield, and Everkeep integrations.
